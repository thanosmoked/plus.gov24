# 텔레그램 봇 버전 설정 가이드

## 1. 텔레그램 봇 생성

1. 텔레그램에서 [@BotFather](https://t.me/BotFather) 봇을 찾아 대화 시작
2. `/newbot` 명령어 입력
3. 봇 이름과 사용자명 설정 (사용자명은 반드시 `bot`으로 끝나야 함)
4. 발급받은 토큰을 복사 (형식: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## 2. 설정 방법

### 방법 1: config.py 직접 수정
```python
# config.py에서 수정
TELEGRAM_TOKEN = "여기에_텔레그램_봇_토큰_입력"
OWNER_ID = 여기에_당신의_텔레그램_유저ID_입력  # 숫자만
```

### 방법 2: 환경변수 사용 (권장)
```bash
# Windows PowerShell
$env:TELEGRAM_BOT_TOKEN="여기에_텔레그램_봇_토큰_입력"
$env:OWNER_ID="여기에_당신의_텔레그램_유저ID_입력"

# Linux/Mac
export TELEGRAM_BOT_TOKEN="여기에_텔레그램_봇_토큰_입력"
export OWNER_ID="여기에_당신의_텔레그램_유저ID_입력"
```

## 3. 자신의 텔레그램 유저 ID 확인하기

1. 텔레그램에서 [@userinfobot](https://t.me/userinfobot) 봇 찾기
2. 봇에게 아무 메시지 전송
3. 봇이 알려주는 `Id` 숫자를 복사

## 4. 필수 패키지 설치

```bash
pip install -r requirements.txt
```

## 5. 봇 실행 방법

### 옵션 1: 텔레그램 봇만 실행
```bash
python telegram_bot.py
```

### 옵션 2: 텔레그램 봇 + 웹 서버 동시 실행 (권장)
```bash
python main_telegram.py
```

## 6. 사용 방법

### 기본 명령어
- `/start` - 시작 및 도움말
- `/register` - 유저 등록
- `/find` - 자신의 ID 확인
- `/aboutme <ID>` - 자신의 정보 확인

### 관리자 명령어 (총관리자만 가능)
- `/관리자추가 <사용자ID>` - 관리자 추가
- `/관리자제거 <사용자ID>` - 관리자 제거
- `/관리자리스트` - 관리자 목록

### 관리자 명령어
- `/라센생성 <일수>` - 라이센스 생성 (예: `/라센생성 30`)
- `/라센리스트` - 라이센스 목록
- `/라센제거 <코드>` - 라이센스 삭제
- `/제작유저 <사용자ID>` - 유저에게 제작 권한 부여

## 7. 민증 제작 프로세스

1. 관리자가 `/라센생성 30` 으로 라이센스 생성
2. 관리자가 `/제작유저 <유저ID>` 로 특정 유저에게 권한 부여
3. 유저에게 라이센스 코드 전달
4. 유저가 봇에게 프라이빗 메시지로 라이센스 코드 입력
5. 봇이 6단계 정보 수집 시작:
   - [1/6] 이름
   - [2/6] 주민등록번호
   - [3/6] 주소
   - [4/6] 발급일자
   - [5/6] 발급지역
   - [6/6] 증명사진 (사진 첨부)
6. 완료 후 웹 링크 수신

## 8. 호스팅 (Render.com 예시)

1. GitHub 레포지토리에 코드 업로드
2. Render.com에서 New Web Service 생성
3. 환경변수 설정:
   ```
   TELEGRAM_BOT_TOKEN=여기에_토큰_입력
   OWNER_ID=여기에_유저ID_입력
   DOMAIN=https://your-app.onrender.com
   ```
4. Start Command 설정:
   ```
   python main_telegram.py
   ```
5. Deploy 클릭

## 10. 문제 해결

### 봇이 응답하지 않는 경우
- 토큰이 올바르게 설정되었는지 확인
- 방화벽/보안 프로그램이 차단하지 않는지 확인
- 봇 실행 로그 확인

### 권한 오류가 발생하는 경우
- `OWNER_ID`가 본인의 텔레그램 유저 ID와 일치하는지 확인
- `/관리자추가` 명령어로 관리자 추가 확인

### 이미지가 표시되지 않는 경우
- `web.py` 파일이 최신 버전인지 확인
- `DB/saved_images` 폴더 권한 확인
- 호스팅 서비스에서 파일 저장이 지원되는지 확인
